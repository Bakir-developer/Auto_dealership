---
description: Ревью текущего git diff — reviewer + security-auditor параллельно
argument-hint: "[необязательно: файлы или область для фокуса]"
---

Проведи ревью текущих изменений (`git status`, `git diff`, плюс новые неотслеживаемые файлы).
Фокус (если указан): $ARGUMENTS

Запусти **параллельно** агентов:
- **reviewer** — стиль по `docs/STYLE_GUIDE.md`, корректность, связи, типы, N+1, ошибки, рамки этапа;
- **security-auditor** — секреты, .env, пароли, SQL-инъекции, права, IDOR, утечки в схемах.

Сведи результаты в один отчёт:
```
🔴 critical — файл:строка — суть
🟡 warning — ...
🟢 suggestion — ...
Итог: N/M/K. Готово к коммиту: да/нет.
```
Ничего не исправляй без отдельной просьбы автора.
